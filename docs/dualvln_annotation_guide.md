# DualVLN Pilot 浏览器标注操作指引

## 开始与保存

本地服务启动后打开 `http://127.0.0.1:8765/`。只使用最终批次，旧候选不能用于正式标签。

1. 填写标注者 ID，例如 `annotator_01`。先试做 3--5 张，确认理解问题，再完成第一轮 40 张。
2. 阅读指令、查看当前 RGB 和专家局部决策。`pixel_goal` 表示专家当前像素目标，当前图上的红色十字标出该点；`turn_right` 表示右转。
3. 查看历史 A/B/C。`age` 是相差帧数，不是秒；A/B/C 已随机排列，不代表时间顺序。相对位置使用当前坐标系，距离以米计，相对朝向以度计。
4. 填写下面的六项字段，然后点“保存并前往下一张”。左右箭头允许保存草稿并跳过，但草稿不计为完成。
5. 输入会自动暂存到当前浏览器的本地存储。刷新能恢复草稿；这不是服务器文件备份，也不会自动生成磁盘上的最终标签。
6. 每完成约 5--10 张就点“导出 JSONL”备份。允许导出部分完成文件，未完成项保留为空，不会强行转为负例。下次在同一浏览器、同一地址继续，或用“导入”恢复对应批次文件。

不要清除浏览器站点数据；不要以无痕模式完成主标注后仅靠自动暂存保存。导出文件默认保存到浏览器下载目录，可通过浏览器另存为放到本项目结果目录下的独立标注文件中。

## 六项字段的判断规则

|字段|怎么判断|
|---|---|
|`need_history`|当前图和指令已足够支持决策选 `no`；历史提供关键补充选 `yes`；无法可靠判断选 `uncertain`。|
|`preferred_evidence`|最多选两张真正有帮助的 A/B/C；没有有用历史选 `none`；不能判断选 `uncertain`。`none/uncertain` 与 A/B/C 互斥。|
|`evidence_role`|定位 `localization`、方向 `direction`、地标 `landmark`、回访 `revisit`、安全 `safety`；无帮助 `none`、不确定 `uncertain`。|
|`misleading_evidence`|只选择可能让当前地点、方向或阶段判断错误的历史；普通无关图像不是误导。没有选 `none`，不能判断选 `uncertain`。|
|`confidence`|依据清楚选 `high`，存在部分歧义选 `medium`，依据薄弱选 `low`。|
|`short_reason`|可选，最多 30 字，只写简短依据，不写长篇思考。|

例：B 中地标确认当前转弯入口，可填 `yes`、`B`、`landmark`、`none`、`high`，原因“B确认地标旁入口”。若当前画面已经足够明确，可填 `no`、`none`、`none`、`none`、`high`。

## 防止标注偏差

只看卡片中的当前和历史信息，不去查看未来帧或完整路线。不因为 B 比 A 老、A 显示在第一位，或某帧看起来相似就选择；判断的是对当前局部决策有无支持。相对 pose 来自仿真数据，不代表真实部署一定拥有理想定位。无法判断时保留不确定，而非勉强凑正负标签。

本批次来自一个已核验场景 `17DRP5sb8fy` 的 20 个 episode，不是跨场景结论。后续需通过一致性和 relevance probe 再决定是否扩展场景与样本。

## 双人复核与交回

完成主标注后保留导出的 `dualvln_annotations_annotator_01.jsonl`。下一步从 40 张中随机抽 10--12 张做第二位标注者的独立复核；第二人使用独立浏览器/配置文件，不导入第一人的答案，使用 `annotator_02` ID。交回两个独立文件，不能用第二人的判断覆盖第一人原始记录。

文件交回后程序检查字段完整性、有效/不确定比例、Top-1/Top-2 一致率、角色分布与显示位置偏差，再开展 relevance probe。未通过前不扩大到 100--200 张、不自动进入训练或闭环。
